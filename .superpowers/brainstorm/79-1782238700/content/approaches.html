How should "add new type" work?

Three approaches for adding a new level type while editing a node

A

Inline — inside the edit dialog מומלץ

The ערוך dialog grows a level dropdown. At the bottom of the dropdown list sits "+ הוסף סוג חדש". Clicking it expands an inline mini-form: a name input and a visual position picker showing the ordered level list with insertion points. Create and select in one step.

✓ No navigation — stays in context
✓ Create the type you need right now
✗ Dialog gets taller when adding
B

Separate settings page

Level types are managed in a dedicated section of System Settings — a sortable list with add/rename/reorder. The ערוך dialog just shows the available types in a plain dropdown with no inline creation.

✓ Clean separation of concerns
✓ Easy to reorder/manage the full list
✗ Must navigate away to add a new type mid-task
C

Gear button → second modal

The ערוך dialog has a level dropdown plus a small ⚙ button beside it. Clicking the gear opens a second modal for managing all types (reorder, add, rename). When done, closes back to the edit dialog.

✓ Management stays near the edit flow
✓ Room to manage the full list
✗ Modal-on-modal layering is awkward
