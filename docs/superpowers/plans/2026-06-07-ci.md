# CI Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a GitHub Actions CI pipeline that runs lint, unit tests, integration tests, and Playwright E2E on every PR and push to `master`.

**Architecture:** Single workflow file (`.github/workflows/ci.yml`) with three jobs: `backend` and `frontend` run in parallel; `e2e` gates on both. Pre-existing ESLint errors are fixed first so the `frontend` job passes.

**Tech Stack:** GitHub Actions, uv (Python), pnpm (Node 20), pytest + testcontainers, Vitest, Playwright, Postgres 16 (service container for E2E only).

## Task 2: Create the GitHub Actions workflow

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Create the workflows directory**

```bash
mkdir -p .github/workflows
```

- [ ] **Step 2: Write `.github/workflows/ci.yml`**

Create the file with this exact content:

```yaml
name: CI

on:
  push:
    branches: [master]
  pull_request:
    branches: [master]

jobs:
  # ─────────────────────────────────────────
  # Job 1: Backend — pytest (testcontainers manages its own Postgres)
  # ─────────────────────────────────────────
  backend:
    name: Backend tests
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: backend

    steps:
      - uses: actions/checkout@v4

      - name: Install uv
        uses: astral-sh/setup-uv@v4

      - name: Cache uv store
        uses: actions/cache@v4
        with:
          path: ~/.cache/uv
          key: uv-${{ runner.os }}-${{ hashFiles('backend/uv.lock') }}
          restore-keys: uv-${{ runner.os }}-

      - name: Install Python dependencies
        run: uv sync --frozen

      - name: Run tests
        run: uv run pytest -q --ignore=app/routes/tests/test_candidate_rank.py

  # ─────────────────────────────────────────
  # Job 2: Frontend — lint + vitest
  # ─────────────────────────────────────────
  frontend:
    name: Frontend lint + tests
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: frontend

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: "20"

      - uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Get pnpm store directory
        id: pnpm-cache
        run: echo "store=$(pnpm store path)" >> $GITHUB_OUTPUT

      - name: Cache pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ steps.pnpm-cache.outputs.store }}
          key: pnpm-${{ runner.os }}-${{ hashFiles('frontend/pnpm-lock.yaml') }}
          restore-keys: pnpm-${{ runner.os }}-

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Lint
        run: pnpm lint

      - name: Unit tests
        run: pnpm exec vitest run

  # ─────────────────────────────────────────
  # Job 3: E2E — full stack (Postgres service + backend + frontend)
  # ─────────────────────────────────────────
  e2e:
    name: E2E tests (Playwright)
    runs-on: ubuntu-latest
    needs: [backend, frontend]

    services:
      postgres:
        image: postgres:16-alpine
        env:
          POSTGRES_USER: db_admin
          POSTGRES_PASSWORD: db_admin_pw
          POSTGRES_DB: cod2
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 5s
          --health-timeout 5s
          --health-retries 10

    env:
      DATABASE_URL: postgresql+psycopg://app:app_pw@localhost:5432/cod2
      DB_ADMIN_URL: postgresql+psycopg://db_admin:db_admin_pw@localhost:5432/cod2
      JWT_SECRET: ci-secret-at-least-32-chars-long!!
      ALLOWED_ORIGINS: http://localhost:5173

    steps:
      - uses: actions/checkout@v4

      # ── Backend setup ──
      - name: Install uv
        uses: astral-sh/setup-uv@v4

      - name: Cache uv store
        uses: actions/cache@v4
        with:
          path: ~/.cache/uv
          key: uv-${{ runner.os }}-${{ hashFiles('backend/uv.lock') }}
          restore-keys: uv-${{ runner.os }}-

      - name: Install Python dependencies
        working-directory: backend
        run: uv sync --frozen

      - name: Run Alembic migrations
        working-directory: backend
        run: uv run alembic upgrade head

      - name: Seed database
        working-directory: backend
        run: uv run python -m app.scripts.seed

      - name: Start backend
        working-directory: backend
        run: uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 &

      - name: Wait for backend
        run: |
          for i in $(seq 1 20); do
            curl -sf http://localhost:8000/docs && break
            echo "Waiting for backend... ($i)"
            sleep 2
          done

      # ── Frontend setup ──
      - uses: actions/setup-node@v4
        with:
          node-version: "20"

      - uses: pnpm/action-setup@v4
        with:
          version: 9

      - name: Get pnpm store directory
        id: pnpm-cache
        run: echo "store=$(pnpm store path)" >> $GITHUB_OUTPUT

      - name: Cache pnpm store
        uses: actions/cache@v4
        with:
          path: ${{ steps.pnpm-cache.outputs.store }}
          key: pnpm-${{ runner.os }}-${{ hashFiles('frontend/pnpm-lock.yaml') }}
          restore-keys: pnpm-${{ runner.os }}-

      - name: Install frontend dependencies
        working-directory: frontend
        run: pnpm install --frozen-lockfile

      - name: Build frontend
        working-directory: frontend
        run: pnpm build

      - name: Start frontend preview server
        working-directory: frontend
        run: pnpm preview --host 0.0.0.0 --port 5173 &

      - name: Wait for frontend
        run: |
          for i in $(seq 1 20); do
            curl -sf http://localhost:5173 && break
            echo "Waiting for frontend... ($i)"
            sleep 2
          done

      # ── Playwright ──
      - name: Install Playwright browsers
        working-directory: frontend
        run: pnpm exec playwright install --with-deps chromium

      - name: Run Playwright tests
        working-directory: frontend
        run: pnpm exec playwright test

      - name: Upload Playwright report
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: playwright-report
          path: frontend/playwright-report/
          retention-days: 7
```

- [ ] **Step 5: If Playwright tests fail**

Download the `playwright-report` artifact from the failed run. Open `index.html` to see screenshots and traces of failing tests.
