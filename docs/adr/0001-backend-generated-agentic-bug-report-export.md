# Generate agentic bug-report exports on the backend

The agentic bug-report Markdown export is generated by an admin-authorized backend endpoint rather than assembled in the browser. The backend has direct access to report snapshots and image blobs, can enforce the active-only scope centrally, and produces a consistent offline ZIP without adding a frontend ZIP dependency or transferring all report data through multiple browser requests.

**Consequences:** ZIP generation is bounded by server memory and request time, but the implementation remains synchronous and simple; an asynchronous export job can be introduced later if report volume makes that necessary.
