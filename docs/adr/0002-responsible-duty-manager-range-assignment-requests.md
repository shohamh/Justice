# Responsible duty manager controls official range assignments

Each scheduled range event has one responsible duty manager. Duty managers outside that manager's scope may see the official range roster and submit assignment requests (בקשה לשיבוץ) only for soldiers within their own scope; admins may submit for any soldier. Requests are visible only to the responsible manager (or a user acting through the existing time-bounded delegation), admins, the nominated soldier, and commanders of nominated soldiers. A request has no requested tier: the responsible manager chooses primary or reserve when approving. Requests are ranked using the normal system eligibility reasons, with creation time as a tie-breaker, but the responsible manager makes the final decision. Requests remain valid when capacity changes and may wait for reserve capacity; they do not count as official capacity or create attendance obligations until approved. The nominated soldier is notified at submission, and approval creates the official assignment and attendance obligation. Rejection, withdrawal, or commander removal records a reason and preserves history. Capacity decisions are transactional, and eligibility is checked again at approval.

**Consequences:** Range visibility, nomination authority, and official-assignment authority remain separate. The feature must integrate with existing hierarchy authorization, candidate ranking, delegation, notification, audit, and official roster semantics; it must not grant approval merely because a duty manager can view a range.
